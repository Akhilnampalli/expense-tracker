# Expense Tracker (Core Version) - MERN

This repository contains a ready-to-upload project for the Round-2 MERN assignment (Core features only).

## Structure
- /backend - Node.js + Express backend (APIs)
- /frontend - React frontend (calls backend APIs)

## Backend
See /backend/README_BACKEND.md

## Frontend
See /frontend/README_FRONTEND.md

## How to run locally
1. Start MongoDB (or use Atlas) and set MONGO_URI in backend/.env
2. Backend:
   - cd backend
   - npm install
   - npm run dev
3. Frontend:
   - cd frontend
   - npm install
   - npm start
4. Open http://localhost:3000
